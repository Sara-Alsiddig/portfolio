# Portfolio

Personal portfolio site for Sara MohammedAhmed, built with React, Vite, and Tailwind CSS.

Live at: https://sara-alsiddig.github.io/portfolio/

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploys automatically to GitHub Pages on push to `master` via the workflow in `.github/workflows`.
